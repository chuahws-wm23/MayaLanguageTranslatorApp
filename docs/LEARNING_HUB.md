# Classic Maya learning hub

Open **Discover Maya writing** from Home or **Learn Maya writing** from the drawer. The existing five bottom destinations are preserved, including History.

The offline hub includes four introductory lessons (word/syllabic signs, glyph blocks, reading order, numbers), eight explanation-backed quiz questions, and a two-level numbers playground for 0–399. Explore mode displays the total and decomposition; Challenge mode asks the learner to build a target before checking it. Repeated checks do not award points. Progress is local to the signed-in account on this device, not cloud-synchronised; it records completed lessons and the best completed quiz score.

Content summarises general conventions described by Harri Kettunen and Christophe Helmke, *Introduction to Maya Hieroglyphs* (Wayeb), and Michael D. Coe and Mark Van Stone, *Reading the Maya Glyphs* (Thames & Hudson). Bibliographic references are shown in the hub and lessons. The material is introductory and is not a substitute for expert interpretation. No scanner output is promoted into a verified quiz answer.

The numbers activity uses ordinary base twenty, not Long Count calendar notation. Its outlined zero is explicitly labelled a simplified shell placeholder, not authentic traced artwork. The lesson explains the Long Count's 360-day exception. No modern Yucatec translation tool is introduced.

Validation covers every supported number's place values and rendered dot/bar counts, invalid range boundaries, and an Android workflow that completes a lesson, answers the full quiz, checks persisted progress, and tries incorrect and correct number challenges. These checks do not measure recognition accuracy.
